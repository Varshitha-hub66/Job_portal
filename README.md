# Job Portal Management System

## 📌 Project Overview
The Job Portal Management System is a web-based application designed to simplify the recruitment process by connecting job seekers and companies on a single platform.

The system allows:
- Companies to post job openings
- Applicants to search and apply for jobs
- Admin to manage users, jobs, and applications

This project helps automate recruitment and reduces manual work.

---

## 🚀 Features

### 👨‍💼 Admin Module
- Secure admin login
- Dashboard management
- Manage job categories
- Manage companies
- Manage applicants
- Manage job vacancies
- View submitted applications
- Update/Delete records

### 👤 Applicant Module
- User registration and login
- Create and update profile
- Upload profile photo/resume
- Browse available jobs
- Search jobs by category
- Apply for jobs online
- Track application status

### 🏢 Company Module
- Company registration and login
- Post new job vacancies
- Edit/Delete posted jobs
- View applicants
- Manage company profile

---

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Java / JSP / Servlets
- Database: MySQL
- Server: Apache Tomcat
