# Job_portal
Job Portal Management System
📖 Project Overview

The Job Portal Management System is a web-based application designed to simplify the recruitment process by connecting job seekers and companies on a single platform. It allows companies to post job openings and enables applicants to search, apply, and track their applications online.

This system provides separate modules for Admin, Applicants, and Companies, ensuring efficient management of job postings and applications.

🎯 Objectives
Automate the job application process
Provide an easy platform for job seekers to find jobs
Help companies manage vacancies efficiently
Reduce manual recruitment work
Maintain applicant and company records securely
✨ Key Features
1. Admin Module

The administrator has full control over the system.

Functionalities:
Secure admin login
Dashboard management
Manage job categories
Manage companies
Manage applicants
Manage employees/users
Manage job vacancies
View submitted applications
Update/delete records
2. Applicant Module

Applicants can create profiles and apply for jobs.

Functionalities:
User registration and login
Create and update profile
Upload profile photo
Browse available jobs
Search jobs by category
Apply for jobs online
View application status
3. Company Module

Companies can post and manage job openings.

Functionalities:
Company registration/login
Add new job vacancies
Edit/delete posted jobs
View applicants for posted jobs
Manage company profile
